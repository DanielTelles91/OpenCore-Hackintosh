# Hackintosh no Asus Z87 Pro

Basic   | Especificação
-------:|:-------------------------
CPU     | Intel i7 4790K
Chipset | Z87
GPU     | Intel HD 4600
Memory  | 16 GB
Release Date | June 2013

__Versão:__

-> Opencore: 1.0.2

-> Mac OS Sonoma e Sequoia

__O que está funcionando:__

-> Áudio (HDMI e ALC)

-> Vídeo (Aceleração 3D e Metal)

-> Gerenciamento de Energia

-> Ethernet

-> O sistema está estável, sem travamentos.

__Obs__:
O áudio via HDMI não está funcionando na versão Sequoia 15.2.
Possivelmente esse problema será resolvido em uma futura versão do Open Legacy Patcher.
